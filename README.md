# 로스트아크 각인 · 아크패시브 최적화

스킬별 딜지분과 치명 수치를 넣으면, 가능한 각인 조합과 아크패시브 진화 노드 조합을 전부 계산해 가장 높은 기대 DPS를 내는 세팅을 추천하는 비공식 계산기입니다.

**바로 쓰기: https://noisywhitecat-dev.github.io/loa-engraving-optimizer/**

설치가 필요 없고, 입력한 값은 사용자의 브라우저에만 저장됩니다. `index.html` 파일 하나만 내려받아 더블클릭해도 똑같이 동작합니다.

## 무엇을 해 주나요

- 5티어 노드 **뭉툭한 가시 / 음속 돌파 / 입식 타격가 / 마나 용광로** 각각에 대해 최적의 각인 5개와 진화 1~4티어 분배를 찾아, 현재 세팅 대비 몇 % 강해지는지 보여 줍니다.
- 어빌리티 스톤의 각인 두 개와, 직업 특성상 쓸 수 있다고 체크한 각인(달인의 저력, 바리케이드, 질량 증가)은 반드시 포함합니다.
- 1티어 치명·신속을 1포인트 단위로, 펫 효과를 치명 또는 신속으로 나눠 봅니다. 특화에 쓸 포인트와 특화 펫은 고정할 수 있습니다.
- 2026-11-18 패치의 **다중 치명타**와 뭉툭한 가시 개편을 반영합니다.

## 입력하는 값

| 구분 | 내용 |
|---|---|
| 캐릭터 | 기본 치명·신속(아크패시브와 펫 제외, 팔찌 포함), 추가 공속·이속, 반지 연마·아크 그리드 등의 기타 수치, 진화 카르마 랭크, 치적 시너지 |
| 팔찌 | 특수 옵션 최대 3개 |
| 어빌리티 스톤 | 각인 2개와 레벨 |
| 스킬 11행 | 스킬 8개, 초각성 스킬, 아이덴티티 스킬, 각성기의 딜지분, 쿨타임 소화 비율, 기본 치적, 트포 치피, 방향과 성공 비율, 차지, 홀딩·캐스팅, 마나 소모량 |
| 현재 세팅 | 딜지분을 측정했을 때의 각인, 진화 노드, 펫 |

딜지분과 쿨타임 소화 비율(전투 시간 중 그 스킬의 쿨타임이 돌고 있는 시간의 비율)은 **현재 세팅에서 측정한 값**을 넣습니다. 결과는 모두 그 세팅과 비교한 값입니다.

## 알아 둘 점

- **기준 패치는 2026-11-18**입니다. 밸런스 패치로 수치가 바뀌면 결과가 달라집니다.
- 특화의 딜 기여는 계산하지 않습니다. 공격 속도는 음속 돌파와 질량 증가 판정에만 씁니다.
- 서포터가 항상 있다고 봅니다(정열의 춤사위 진화형 피해 +12%, 축복의 여신 공이속 +9%).
- 합연산·곱연산 분류, 스탯 환산 계수, 쿨감 묶음 규칙은 공식 문서가 아니라 커뮤니티 실측 자료에 근거합니다. 각성기에 진화형 피해가 적용되는지는 실측 자료를 찾지 못해 "적용"으로 계산합니다.
- 계산 규칙과 출처는 [research/damage_model_research.md](research/damage_model_research.md)에 정리돼 있습니다.

## 개발

외부 라이브러리 없이 `index.html` 하나로 되어 있습니다. 계산 엔진은 파일 안의 `<script id="engine">` 블록이고, 테스트가 이 블록을 꺼내 검증합니다.

```
node research/run_all.js
```

Node.js와 Python 3가 필요하고 2분쯤 걸립니다. 수치 대조, 불변식, 전수 탐색 검증, 난수 시뮬레이션, Python으로 따로 구현한 모델과의 대조를 돌립니다. 브라우저 화면 테스트는 [research/ui_test.js](research/ui_test.js) 머리말의 방법으로 실행합니다.

패치로 수치가 바뀌면 `index.html`의 `ENGR`, `BRACELET`, 노드 수치와 `research/test_properties.js`의 기대값을 함께 고친 뒤 테스트를 돌립니다.

## 안내

개인이 만든 비공식 도구이며 스마일게이트 RPG와 관련이 없습니다. 로스트아크와 관련 명칭의 권리는 해당 권리자에게 있습니다. 인게임 실측으로 검증하지 않은 규칙이 있으니 참고용으로 써 주세요.
